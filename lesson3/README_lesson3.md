## 4. C++ 工程中常见的编译与链接问题

在多文件 C++ 项目中，代码写完并不代表一定能够成功构建。请结合实际工程，思考并尝试解决以下问题：

1. **头文件找不到**：出现 `fatal error: xxx.hpp: No such file or directory` 时，如何判断是 `#include` 路径写错，还是编译器缺少头文件搜索路径？
2. **未定义引用**：代码能够通过编译，但链接时出现 `undefined reference to ...`，可能有哪些原因？如何检查是否遗漏了 `.cpp` 文件或库？
3. **重复定义**：多个 `.cpp` 文件包含同一个头文件后，为什么有时会出现 `multiple definition of ...`？头文件保护宏或 `#pragma once` 能否解决所有重复定义问题？
4. **编译成功但运行失败**：可执行文件已经生成，运行时却提示找不到共享库（如 `error while loading shared libraries`），这与编译时找不到头文件有什么区别？
5. **修改代码后结果没有变化**：为什么重新运行程序后仍然是旧行为？如何确认自己执行的是刚刚编译生成的程序？

**学习要求：** 不必背诵所有报错信息，但应能够区分编译错误、链接错误和运行时错误，并根据报错信息定位问题发生的阶段。

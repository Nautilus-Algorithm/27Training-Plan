# 算法组方向介绍｜视觉与导航

本次分流主要帮助大家了解 RoboMaster 算法组中**视觉**和**导航**两个方向的工作内容、学习重点与后续培养路线。两个方向都需要 C++、Linux 和基本工程开发能力，没有绝对的难易之分。

## 一、视觉方向

**核心目标：让机器人能够识别、定位、跟踪目标，并为自动瞄准提供信息。**

典型工作流程：

`相机采集 → 目标识别 → 位姿估计 → 目标跟踪与预测 → 瞄准解算 → 输出控制信息`

**学习重点**

- **图像处理与目标识别**：OpenCV、装甲板检测，了解传统视觉与深度学习方法。
- **空间定位**：相机标定、坐标变换、PnP 位姿估计。
- **状态估计与预测**：卡尔曼滤波、运动模型、目标跟踪。
- **工程调试**：实时性、识别稳定性、定位精度及自瞄效果。

**建议培养路线**

1. **工程入门**：巩固 C++、Linux、CMake、Git，能够编译、运行并阅读现有视觉项目。
2. **视觉基础**：学习 OpenCV、相机基础，完成简单的图像处理与目标检测任务。
3. **核心模块**：逐步理解并实践位姿解算、目标跟踪与预测等模块。
4. **项目实战**：参与视觉系统联调，定位实际问题并持续优化效果。

## 二、导航方向

**核心目标：让机器人理解自身位置与周围环境，并自主规划和执行运动。**

典型工作流程：

`传感器数据 → 定位与建图 → 环境表示 → 路径规划 → 运动控制 → 底盘执行`

**学习重点**

- **机器人基础**：ROS 2、坐标系、TF、里程计及传感器数据。
- **定位与地图**：SLAM 基础、栅格地图、代价地图等环境表示。
- **路径规划**：A*、JPS 等路径搜索算法与避障思路。
- **运动控制**：路径跟踪、PID、MPC 等控制方法及实际调试。

**建议培养路线**

1. **工程入门**：巩固 C++、Linux、CMake、Git，了解 ROS 2 的基本使用。
2. **导航基础**：理解坐标系、地图、定位与路径的基本概念，能够运行和观察现有导航系统。
3. **核心模块**：学习路径规划和运动控制，尝试修改、测试独立模块。
4. **项目实战**：参与仿真与实车联调，分析定位、规划和控制中的实际问题。

## 三、两个方向如何选择？

| 对比项 | 视觉 | 导航 |
| --- | --- | --- |
| 主要解决的问题 | 看见目标、判断目标状态、辅助瞄准 | 知道自己在哪、决定怎么走、稳定移动 |
| 主要输入 | 相机图像等 | 雷达、IMU、里程计、地图等 |
| 常见技术 | OpenCV、PnP、卡尔曼滤波 | ROS 2、SLAM、A*、MPC |
| 日常工作 | 图像与识别效果分析、目标定位和跟踪调试 | 地图与轨迹分析、规划和控制调试 |
| 更适合的兴趣倾向 | 喜欢图像、识别、目标跟踪 | 喜欢机器人运动、路径规划、系统联调 |

**分流建议：**优先考虑自己更愿意长期接触哪类问题，而不是只看算法名称。两个方向都需要持续阅读代码、做实验、分析日志，并把算法真正运行到机器人上。

> 注：以上是通用的方向介绍。具体模块分工与培养任务，以战队实际项目和负责人安排为准。
